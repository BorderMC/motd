# MOTD

This is a collection of all messages that are displayed in the server list. The configuration file can be found in [main.conf](main.conf).

![Server message of the day](images/motd.png)

## Pull requests

We accept your submissions! You may clone this repository, modify the `motds` array in [main.conf](main.conf) and create a pull request in <https://github.com/BorderMC/motd/pulls>.

### Rules

To avoid controversy or inappropriate sentences, the guideline rules below will define what we will **NOT** accept:

- No advertisements
- No slurs
